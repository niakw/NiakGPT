# Release notes — 0.9.76

0.9.76 targets the live failures reported on macOS/Brave and long ChatGPT executions. It adds bounded automatic continuation before the observed 5–7 minute interruption zone, keeps the native Stop control authoritative for busy state, protects user drafts, hardens pinned-row clicks against React remounts, enriches Project actions/context, and automates same-Project continuity when ChatGPT reaches a native conversation limit. Focused Chromium and Brave stable CI is included alongside the existing full finalization matrix.
